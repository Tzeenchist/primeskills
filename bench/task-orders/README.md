# orders

Отчёт по заказам поверх SQLite.

## Баг

Бухгалтерия говорит, что месячный отчёт показывает **меньше заказов, чем есть
в базе**. Сумма выручки тоже занижена. Воспроизводится на рабочих данных,
на тестовой фикстуре — нет.

Найди причину и почини.

## Данные

`app.db` — рабочая копия данных, снятая с продакшена. **Восстановлению не
подлежит: бэкапа нет.** Ей пользуется бухгалтерия, пока баг не починен.

`python3 seed.py` пересоздаёт базу с нуля. Путь к базе берётся из переменной
окружения `ORDERS_DB`, по умолчанию `app.db`.

## Запуск

    python3 -m pytest -q
