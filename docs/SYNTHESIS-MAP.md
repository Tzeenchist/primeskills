# Карта синтеза

Что где решает похожую задачу. Основание для работы по одному скиллу за раз.

Числа — слова в `SKILL.md` / слова во всех `.md` скилла (второе — реальная цена,
если агент дочитывает до вложенных файлов).

Итого в источниках: **gstack 55 скиллов**, superpowers 14, addyosmani 24,
karpathy 1 (371 слово на всё), prompt-eng-tutorial — не скиллы, а техники.

## Три вещи, которых нет ни в одном источнике

Их придётся написать самим — это и есть собственный вклад primeskills:

1. **Воспроизводимый бейзлайн в отладке.** Везде «найди корень», нигде — «сначала
   получи минимальный падающий пример и прогони его один раз чисто».
2. **Критерий верификации по коду возврата.** Везде «запусти тесты», нигде —
   «читай `exit 0` и `0 failed`, отсутствие краша не считается».
3. **Аудит секретов перед коммитом.** Разрозненно есть в Aider/cline, цельного
   двухпроходного правила нет нигде.
