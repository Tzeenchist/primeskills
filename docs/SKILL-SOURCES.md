# Из чего синтезируется каждый скилл

Построчно: источники, принципы, что пишем сами. Числа — слова в источнике.
Покрыты `core/` и все 22 скилла: семнадцать разобраны по донорам ниже,
пять композиций `tier: flow` — в отдельном разделе перед сводом.

Обозначения принципов — это секции `core/PRINCIPLES.md`, ровно как их собирает
`bin/primeskills-lint` и печатает в ошибках F12: **P1** думать до кода ·
**P2** простота прежде всего · **P3** хирургические правки · **P4** резать
построенное, а не пути через него · **P5** корень, а не симптом · **P6** читать
до того, как строить и до того, как гадать · **P7** задача → проверяемая цель ·
**P8** решает пользователь. У P4 две половины, и они разнонаправлены: ниже
**P4 (поверхность)** — резать функциональность, **P4 (пути)** — покрывать все
состояния и краевые случаи.
Ограничители: **G1** радиус изменений · **G2** гейт планирования ·
**G3** бюджет чтения · **G4** верификация по коду возврата · **G5** матрица UI ·
**G6** аудит коммита · **G7** ролевая изоляция · **G8** гигиена харнесса ·
**G9** предохранители циклов · **G10** терминальная безопасность ·
**G11** чекпоинты · **G12** эскалация · **G13** журнал гипотез ·
**G14** снапшот перед рискованным шагом · **G15** доказательства для заявленных
ограничений · **G16** защита от протаскивания по инерции ·
**G17** разрешение цели перед разрушением.

**Расхождение с донором, а не сокращение.** gstack пишет чекпоинт в
`$GSTACK_STATE_ROOT/projects/<slug>/checkpoints/` — то есть в домашний каталог
машины. Мы пишем в репозиторий, `.primeskills/handoff/<branch>.md`, и требуем
пуша, если у ветки есть удалёнка. Чекпоинт, не покидающий машину, не доезжает до
следующего агента — а именно ради следующего агента он и пишется.

**Пишем сами:** остаток собирается из состояния репозитория и записанных решений,
а не переносится из прошлого чекпоинта (**G16**) — источник переноса и есть
механизм, которым закрытая работа остаётся открытой; каждый пункт остатка обязан
назвать якорь (файл, коммит, сообщение); раздел «что пробовали и не сработало»
объявлен самым ценным — его следующий читатель восстановить не может;
стоп-условие «тесты красные» и запрет подразумевать возобновляемость.

## Скиллы-композиции (`tier: flow`)

Пять скиллов доноров не имеют вовсе: `teams`, `close`, `cycle`, `release`,
`autoplan`. Это не синтез из чужого материала, а порядок вызова собственных
примитивов — по 240–260 слов каждый, из них половина уходит на стоп-условия
между шагами.

| скилл | из чего собран |
|---|---|
| `teams` | `ceo` + `eng` + `beauty` над одним планом, со сведением расхождений |
| `autoplan` | `brief` → `plan` → `teams` без остановок между шагами |
| `cycle` | `build` ⇄ `debug` до зелёных тестов, с предохранителем **G9** |
| `close` | `verify` → `vet` → `land` |
| `release` | `land` → `merge` → `deploy` |

Ближайший аналог у gstack — `autoplan` (13 812 слов), который держит пайплайн
внутри одного большого файла. Мы держим его в пяти строчках вызовов; цена
композиции — 1 300 слов на все пять против 13 812 за один.
