# primeskills

*[English](README.md) · Русский*

Набор инструкций для агента-программиста — того, что пишет код по вашей просьбе:
Claude Code, Codex, Kimi Code, OpenCode. Каждая инструкция покрывает один род
работы: как искать причину бага, как проверить изменение, как передать работу
дальше.

Такие наборы обычно занимают место в голове у агента постоянно. Этот — почти
нет. Полный текст инструкции подгружается, только когда она нужна.

> Я люблю gstack и пользовался им с момента появления, но сейчас он стал
> настолько жирным и дорогим, что скоро сам Гэрри Тэн его не потянет.
> Агентская разработка — это экономия: усилий, времени, денег. Этой философии я
> и придерживался, создавая PRIMESKILLS. Сейчас этот набор содержит всё лучшее
> и надёжное из того, чем я ежедневно пользуюсь для разработки программных
> продуктов.
>
> — Илья Приймак, автор набора

```
постоянно в контексте        466 слов на все 29 навыков
общие правила                2 805 слов, один раз за сессию
один вызов навыка            3 553 … 3 971 слов
```

**Потолок одного вызова навыка — 4 600 слов** (правило C3), и его держит
проверка, а не обещание: линтер откажется принять навык, который выводит вызов
за потолок. Последовательность платит за всю цепочку и вынесена за этот потолок
намеренно — сколько стоит каждая, печатает `primeskills-status`: до ~6 250. Для
сравнения, один проход набора gstack стоит около 92 000 слов — замер в
`bench/RESULT.md`.

## Дисциплина и доказательство

**Порядок вместо памяти.** Падающий тест раньше кода. «Прошло» — это код
возврата и число тестов, а не отсутствие ошибки в выводе. Перед разрушительной
командой вслух назвать, чего она коснётся. Три неудачные попытки на одной
проблеме — остановиться и спросить.

**Доказательство переживает сессию.** Результат прогона тестов записывается на
диск вместе с отпечатком состояния дерева. Изменили файл после зелёного прогона
— запись протухла, и следующий шаг это увидит. Агент не может сослаться на
проверку, которой не было, или на ту, что относилась к другому коду.
Игнорируемые входы тестов можно включить в отпечаток через
`.primeskills/digest-include`: один glob от корня репозитория на строку,
комментарии начинаются с `#`. Для неотслеживаемых файлов больше 4 МБ берутся
размер, первые и последние 64 КиБ; для симлинков — путь и цель ссылки, без
чтения по ссылке и выхода из репозитория.

**Полномочия по ступеням.** Коммит, пуш, pull request, слияние, миграции,
выкатка, откат, удаление, сброс счётчика отказов — девять отдельных «да».
Разрешение на одно не
открывает следующее, разрешение для staging не открывает production, а
разрешение на одну выкатку не действует на завтрашнюю.

**Чужой текст — данные, а не приказ.** Инструкции репозитория, issue,
документация зависимости, страница в сети: агент проверяет их, а не исполняет
найденную внутри команду. И не запускает чужой код раньше, чем посмотрит на
дифф.

**Наружу не уходит ничего от самого набора.** Ни телеметрии, ни обращений
домой, ни зависимостей. К чему тянется сам навык — вопрос отдельный и объявлен
открыто: аналитическим разрешены `WebFetch` и `WebSearch`, потому что чтение
документации и есть их работа.

## Агенты

| агент | как ставится |
|---|---|
| Claude Code | навыки + указатель на общие правила в `CLAUDE.md`, ограничители в `settings.json` |
| Codex | навыки + указатель в `~/.codex/AGENTS.md` |
| Kimi Code | `extra_skill_dirs` в конфиге + указатель + профиль `prime-analyst` |
| OpenCode | навыки + общие правила в `instructions` + профиль `prime-analyst` |

У аналитических навыков отобраны редактирующие инструменты, и хосты это
соблюдают. Оболочка — отдельный канал, её не перехватывает никто, поэтому
изоляция ролей здесь дисциплина, а не стена; набор говорит это прямо, а не
подразумевает.

## Требования

Python 3.11 или новее и git. Больше ничего: пакеты не ставятся, сеть не
нужна. Нижнюю границу задаёт `tomllib` — им установщик читает конфиг Kimi.

## Установка

```
git clone <репозиторий> primeskills
cd primeskills
python3 bin/primeskills-install            # печатает план, ничего не меняет
python3 bin/primeskills-install --apply    # раскладывает по всем найденным агентам
python3 bin/primeskills-doctor             # проверяет, что всё подключено
```

По умолчанию установка закрепляется на коммите: агенты читают отдельное дерево,
и правка в рабочей копии на них не влияет, пока вы не поставите заново. Для
разработки самого набора это лишнее:

```
python3 bin/primeskills-install --apply --live   # ставить с рабочей копии
python3 bin/primeskills-install --pin <коммит>   # закрепить другой коммит
python3 bin/primeskills-install --unpin          # вернуться на рабочую копию
```

Установщик забирает только то, что положил сам: чужие навыки и ваши файлы
внутри его каталогов он не трогает. Снять — `--uninstall --apply`.

**Что именно он пишет в Claude Code.** Вместе с навыками установщик добавляет
хуки `PreToolUse` в `~/.claude/settings.json`. Это значит, что перед каждым
вызовом `Bash`, `Edit` и `Write` запускается программа из этого репозитория и
может вызов отклонить — так `fence` останавливает разрушительную команду вместо
того, чтобы просить её помнить. Это же и самое сильное действие набора на вашей
машине, поэтому решайте про него осознанно: в строках хуков стоит абсолютный
путь, закреплённое дерево в обычной работе не меняется, снимаются они через
`--uninstall --apply`. Больше хуков не ставит никто — у трёх остальных агентов
такого механизма нет вовсе.

**Когда подтверждения выключены, сторож перестаёт спрашивать.** В сессии с
`--dangerously-skip-permissions` — и в любом режиме, где вы сказали «не
спрашивай меня» — вопрос перестаёт быть защитой: на него отвечают «да», не
читая, а привычка отвечать не глядя останется и на том вопросе, который был
важен. Поэтому сторож решает сам. Короткий список необратимого он отклоняет:
содержимое баз, force-push, ресурсы кластера, запись поверх устройства,
удаление за пределами рабочего каталога. Всё остальное проходит, оставляя
строку в журнале прогона. Отказ снимается так же, как выдаётся любое
разрешение: скажите агенту, что именно позволяете, и он запишет ваш ответ.

## Навыки и цепочки

Навык можно вызвать самому — `/debug`, — но обычно не приходится: агент
выбирает по описанию. Пять навыков вызывают другие по порядку и останавливаются
там, где решение ваше.

```
/autoplan   идея → бриф → план → разбор тремя ролями
/cycle      реализация → проверка → отладка, пока не зелено
/close      проверка → ревью диффа → прогон приложения → pull request
/release    pull request → слияние → выкатка
/teams      разбор плана: продукт, инженерия, интерфейс
```

Остальные вызываются поштучно. Здесь они все, потому что мелкие своё место
отрабатывают: `/baby` и `/prose` — из самых ходовых.

<!-- skills:begin -->
```
# понять задачу, код и слова
/brief        чего на самом деле хотят и что выкинуть
/study        как устроен незнакомый код
/baby         термин или прошлый ответ — простыми словами

# решить, что строить
/plan         разбить на шаги, когда требования ясны
/ceo          та ли это работа вообще
/money        как окупится то, что этот план добавляет
/eng          архитектура, потоки данных, краевые случаи, тесты
/beauty       состояния интерфейса, иерархия, клавиатура, контраст

# написать и доказать
/build        реализация, сперва падающий тест
/debug        найти причину, а не симптом
/verify       доказательство прежде слов «проходит»

# проверить, что вышло
/vet          прочитать дифф до слияния
/probe        погонять живое приложение и назвать баги
/measure      куда на самом деле уходит время
/ui           состояния, которые интерфейс должен пользователю

# отдать
/revise       ответить на каждое замечание ревью
/land         коммит, пуш, pull request
/merge        слить, когда CI зелёный
/deploy       выкатить, заранее имея путь назад
/handoff      сохранить состояние для следующей сессии
/handon       вернуться к сохранённому чекпоинту, выбрав его из списка

# держать сессию честной
/fence        сторожа на разрушительные команды и чужие правки
/prose        снять машинные приметы, не выхолостив текст
/primeskills  напечатать руководство по набору
```

Полное руководство печатает `primeskills-help` — на вашем языке, любом:
`primeskills-help --set-lang <язык>`, и выбор запоминается.

## Команды

```
primeskills-help              руководство по набору
primeskills-doctor            подключено ли всё у каждого агента
primeskills-status            состав набора и его вес, из репозитория
primeskills-run show          запись прогона текущей ветки
primeskills-run ship          прогон + запись в журнал + открытые ступени одним вызовом
primeskills-handoffs          какие чекпоинты сохранены в этом дереве
primeskills-adherence --all   соблюдались ли инварианты вызванных навыков
primeskills-lint              формат навыков: правила F и C — включая G16 (F16) и средство выбора (F17)
primeskills-release           описание релиза; навыки с изменениями должны быть вызваны живьём во всех четырёх хостах
python3 tests/run.py          весь прогон
```

Числа в документах не набираются руками: их читает `primeskills-status` из
самого репозитория.
