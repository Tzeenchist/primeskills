# Признаки машинного текста, по языкам

**Пороги ниже — авторские эвристики, а не измеренная человеческая норма.** Они годятся, чтобы заметить приём, и не годятся, чтобы заявить, что текст «проходит за человеческий»: такого измерения за ними нет.

Числа — грубые пороги на тысячу слов, за которыми приём превращается в
механику. Ниже порога не трогать: это письменная речь, а не дефект.

## Общее для обоих языков

| приём | порог | чем плох |
|---|---|---|
| разворот «не X, а Y» | 2 | одна штука — приём, шесть — конвейер |
| тройки («быстро, надёжно и удобно») | 3 | ритм трёх усыпляет, а третий член обычно лишний |
| абзац, кончающийся ударной строкой | 3 | текст начинает читаться как лента цитат |
| абзацы одинаковой длины | 4 подряд | метроном; живая речь рваная |
| наречия усиления | 5 | «действительно», «крайне», «really», «truly» |
| риторический вопрос вместо утверждения | 2 | вопрос, на который автор сам отвечает |
| заголовок-анонс вместо названия | любой | «Что это меняет» вместо «Схема миграции» |

## Только русский

**Тире — норма, а не признак.** В русской типографике тире ставится вместо
пропущенной связки («Москва — столица»), в диалоге и при приложении. Правило
английских руководств «no em dashes» здесь удаляет правильную пунктуацию.
Проверять нечего.

| приём | порог | пример |
|---|---|---|
| канцелярские зачины | 2 | «важно отметить», «стоит подчеркнуть», «следует сказать» |
| пустые усилители | 3 | «ключевой», «мощный», «инновационный», «поистине» |
| «в современном мире», «в наши дни» | 1 | почти всегда выбрасывается без потери |
| «не только… но и» | 2 | та же бинарная конструкция, что и «не X, а Y» |
| «давайте разберёмся», «итак» | 1 | зачистка горла перед мыслью |
| связки подряд | 3 | «при этом», «таким образом», «более того» в соседних абзацах |
| отглагольные существительные | 6 | «осуществление внедрения» вместо «внедрили» |
| следы чат-бота | 1 | «надеюсь, это поможет», «хотите, я распишу» |
| деепричастный хвост | 3 | «подчёркивая», «отражая», «обеспечивая» |
| уход от связки | 3 | «является», «представляет собой» вместо тире |
| туманная атрибуция | 1 | «эксперты считают», «по мнению аналитиков» |

## Только английский

| приём | порог | пример |
|---|---|---|
| em dash | 4 | здесь перебор действительно читается как машина |
| «It's not just X, it's Y» | 2 | тот же разворот |
| «Here's the thing», «Let's dive in» | 1 | зачистка горла |
| «delve», «leverage», «robust», «seamless» | 2 | словарь, по которому текст узнают |
| «In today's fast-paced world» | 1 | выбрасывается целиком |
| pull-quote sentences | 3 | строка, просящаяся в цитату |

## Следы авторской сессии

Отдельный класс, который не ловится частотой: текст написан с точки зрения
сессии, а не репозитория. Проверяется одним вопросом.

**Сможет ли читатель, у которого есть только текущее состояние — без
переписки, без черновиков, без истории правок — разрешить каждую ссылку и
проверить каждое утверждение?**

Нет — переписать выжившие факты от лица текущего состояния, остальное убрать.

| что | пример | чем заменить |
|---|---|---|
| ссылки на невидимое | «как решили в пункте 7», «см. черновик §4» | назвать источник по имени и пути или снять ссылку |
| рассказ об изменении | «раньше было», «в первой редакции», «теперь мы» | описать нынешнее поведение |
| спор с ревьюером | «это безопасно, потому что…» | назвать инвариант, который делает это безопасным |
| остатки планирования | «пока сойдёт», «наверное, хватит» | точная граница или пометка `TODO` |

**Не следы:** «без X происходит Y» (контрфактическое настоящее), «(замерено:
0,15 с)» (провенанс несёт нагрузку), «старое соединение доживает раньше, чем
новое принимает» (это жизненный цикл, а не история правок).

## Как считать

```
grep -oiE 'не только|важно отметить|таким образом' файл | wc -l
grep -c '—' файл          # только для английского текста
awk 'NF{n++} END{print n}' файл    # абзацы, чтобы получить долю
```

Считать до правки и после. Отчёт без чисел — впечатление, а не проверка.

## Чего этот список не ловит

Мёртвую структуру: три раздела одинаковой формы, вступление, пересказывающее
оглавление, вывод, повторяющий вступление. Это видно только чтением целиком, и
для этого в процедуре отдельный шаг.
